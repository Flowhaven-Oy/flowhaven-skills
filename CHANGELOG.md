# Changelog

## flowhaven-insights 1.0.0 (November 2026)

Initial release.

- Read-only questions about agreements, minimum guarantees, granted rights, submissions, design approvals and royalty reports in a connected Flowhaven org.
- Org survey on first use: org name, sandbox or production, Flowhaven package check and connected user access.
- Health checks for minimum guarantees, royalty reports and coverage.
- Summaries, tables and dashboards built from query results, with the query basis shown.
- Requests to change data are declined with an offer to draft the record instead.
- Installable from this repository as a Claude plugin marketplace (plugin `flowhaven-suite`), or by uploading the zip.
